# Getting Support

Thanks for using NexQ. Here is where to go for help.

## Start with the docs

Most setup questions are answered in the user guide:

- [Getting started](docs/user-guide/getting-started.md)
- [Audio setup](docs/user-guide/audio-setup.md): microphones, system audio, devices
- [Choosing AI providers](docs/user-guide/ai-providers.md): STT and LLM options, local vs cloud
- [Claude subscription](docs/user-guide/claude-subscription.md): using your Claude Pro/Max login
- [Context and RAG](docs/user-guide/rag-context.md)
- [Keyboard shortcuts](docs/user-guide/keyboard-shortcuts.md)
- [Troubleshooting](docs/user-guide/troubleshooting.md)

## Ask a question

For "how do I...?" questions, setup help, ideas and show-and-tell, use
**[GitHub Discussions](https://github.com/naxhq/NexQ/discussions)**. Others can find and
benefit from the answer there, and the issue tracker stays focused on actionable work.

## Report a bug or request a feature

Use the [issue forms](https://github.com/naxhq/NexQ/issues/new/choose). Before opening one:

1. Update to the [latest release](https://github.com/naxhq/NexQ/releases/latest); the bug may already be fixed.
2. Search [existing issues](https://github.com/naxhq/NexQ/issues?q=is%3Aissue), including closed ones.
3. Include your NexQ version, OS, STT and LLM providers, and **your log**: in NexQ, open
   **Settings → About → Diagnostics** and click **Copy recent log**. See
   [collecting logs](docs/user-guide/troubleshooting.md#collecting-logs-for-a-bug-report).

## Security issues

Never report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md) to report privately.

## What to expect

NexQ is maintained by volunteers. We read everything, but responses can take a few days.
There is no paid support. Clear, reproducible reports get fixed fastest, and pull requests
are the quickest route of all; see [CONTRIBUTING.md](CONTRIBUTING.md).
